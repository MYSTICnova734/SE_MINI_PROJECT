# Appendices

## Glossary

| Term | Definition |
| :--- | :--- |
| **ADR** | Architecture Decision Record |
| **API** | Application Programming Interface |
| **bcrypt** | Adaptive cryptographic hash function for passwords |
| **JWT** | JSON Web Token used for session authorization |
| **ORM** | Object-Relational Mapping library |
| **RBAC** | Role-Based Access Control |
| **SAD** | Software Architecture and Design Specification |
| **STRIDE** | Threat modeling framework (Spoofing, Tampering, Repudiation, Information Disclosure, DoS, Elevation of Privilege) |
| **TLS** | Transport Layer Security encryption protocol |

## References

* **NIST SP 800-63B:** Digital Identity Guidelines & Password Management Recommendations.
