# 14. Test Metrics & Reporting

## Metrics collected

* % test cases executed: $(\text{Executed Test Cases} / \text{Total Planned}) \times 100\%$.
* % passed/failed: $(\text{Passed Test Cases} / \text{Executed Test Cases}) \times 100\%$.
* Defect density: Identified defects per 1,000 lines of code.
* Defect aging: Mean time from defect logging to resolution.
* Requirement coverage: $(\text{Verified Requirements} / \text{Total Requirements}) \times 100\%$.

## Reports

* Daily execution status log.
* Final Test Summary & Acceptance Report.
